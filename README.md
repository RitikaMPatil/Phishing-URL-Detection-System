# 🛡️ Phishing URL Detection System

A Machine Learning-based cybersecurity web application that detects and classifies phishing URLs to protect users from malicious websites and online fraud.

---

# 🚀 Features

- Real-time phishing URL detection
- Machine Learning-based prediction
- Responsive modern UI
- React.js frontend
- Flask backend API
- Cybersecurity-focused application
- Fast and lightweight system
- URL feature extraction
- Random Forest ML model

---

# 🛠️ Tech Stack

## Frontend
- React.js
- Vite
- Tailwind CSS
- Axios

## Backend
- Flask
- Flask-CORS

## Machine Learning
- Scikit-learn
- Pandas
- NumPy
- Random Forest Classifier
